## 비고

- A1, A2가 먼저 끝났으므로 "시간 지연/발사 시뮬레이션" 프로젝트 쪽에서 로켓 불러오기 기능(그 저장소의
  16단계)을 이 저장소의 A3~A6 완료를 기다리지 않고 `examples/falcon_heavy.rocket.json`으로 먼저
  개발·검증할 수 있다.
- A4는 요구사항 R-02(부품을 3D 장면에 직접 드래그해 연결점에 붙이는 자유 조립)를 완전히 만족하지 못하는
  단순화 버전이다. 대신 "부품 목록에서 종류를 고르고 단 카드에 배정하는" 방식으로 구현했다 — 3D 장면은
  그 결과를 보여주는 미리보기 역할이다. 자유 드래그+스냅으로의 개선 여부는 사용성 피드백을 받은 뒤
  DECISIONS.md에 기록하고 진행한다.
- 불러오기(R-08)로 복원한 설계를 다시 내보내면 원본 JSON의 `dryMassKg` 등 숫자가 그대로 보존되지
  않고 카탈로그 부품 조합으로 다시 계산된 값으로 바뀔 수 있다 (예: 팔콘 헤비 예제를 불러온 뒤 바로
  다시 내보내면 총질량이 원본과 조금 달라짐). 이 도구가 "숫자를 저장하는 파일"이 아니라 "부품 조합을
  저장하는 파일"을 다루는 조립 도구이기 때문이며, DECISIONS.md에 기록했다.
- 테스트 실행 방법: 이 개발 환경에 Node.js가 설치되어 있지 않아, `node tests/*.test.js`(README 방식)
  대신 정적 서버로 `tests/browser-check.html`과 `index.html`을 열어 브라우저에서 검증했다 (전체 통과,
  실제 조립 UI 조작도 확인). Node가 설치되면 `tests/*.test.js`도 그대로 통과해야 한다. DECISIONS.md에 기록.
